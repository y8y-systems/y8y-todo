# y8y Branding — Name, Logo and Trademark Usage

This document explains how the **y8y** name, the **y8y Todo** product name
and the official y8y logo may be used. It governs **brand assets only** —
the software source code is licensed separately under the MIT License
(see [LICENSE](LICENSE), [NOTICE](NOTICE)).

> **Short version: the code is open source (MIT); the brand is not.**
> You may freely use, modify and commercialize the software. You may not
> use the y8y logo as your own brand or product identity without
> permission.

The official logo is the pixel-cat mark holding a TODO sign. Its vector
master is `vendor/y8y-shared-chrome/brand/y8y-logo.svg` (a 19×19 pixel
grid); the app loads that master directly, so the browser renders it as
vector art at any size and device-pixel ratio. It is an in-house brand
asset, not MIT-licensed open-source material.

## 2. Using the official software — no permission needed

You may, without asking us:

- download, install and run the official y8y Todo;
- let the unmodified official software display the official logo;
- copy and redistribute the official software **unmodified**, logo included;
- make screenshots, tutorials, videos and articles about the official
  project, showing the logo as it appears in the software.

## 3. Modified versions and forks — MIT code, your own brand

The MIT License lets anyone fork, modify and commercialize the source code.
That code permission does **not** include the right to use the y8y logo as
your own product's brand.

- A modified or derived distribution should use **its own** logo and name.
- You may state the truth about provenance — for example "Based on y8y
  Todo" or "Forked from y8y Todo" — as long as the statement is accurate.
- You must not imply that your version is an official release, or that it
  is certified, endorsed or commercially authorized by y8y.
- Forking this repository on GitHub technically copies the logo file
  together with the code. That technical copy is permitted by the brand
  asset license; using the copied logo as your own brand is not.

## 4. Prohibited without prior written permission

- registering the y8y logo (or a confusingly similar mark) as your own
  brand, trademark or company identifier;
- using the logo as the primary brand of another product or service;
- making or selling merchandise that features the logo;
- selling the logo itself, alone or inside asset packs;
- using the logo to impersonate the official project, website or
  organization;
- packaging a product in a way that implies official y8y affiliation.

Reasonable project introductions and truthful references (§5) are distinct
from unauthorized commercial brand use and remain allowed.

## 5. Talking about y8y Todo is always fine

Reasonable, truthful references need no permission:

- technical articles, tutorials and videos;
- software reviews and comparisons;
- academic research and citations;
- open-source dependency or provenance listings;
- a fork's source statement.

## 6. What this document does not do

- It does not restrict any right the MIT License grants you for the
  software source code.
- It does not grant ownership in the y8y name or logo. No trademark
  registration is claimed or implied here.
- Distributing the logo with the official software does not transfer brand
  ownership.
